# GitHub Pages fidelity ledger — 2026-08-27

Reference: `github-pages-2026-08-27-concept.png`

1. **Message and hierarchy preserved.** The implementation keeps the exact hero
   promise, primary navigation order, paired workflow/evidence calls to action,
   and the concept's overview → workflow → evidence → safety → install sequence.
2. **Product visual preserved with safe media.** The browser-built ECG window
   retains four blue finding boxes, two dashed crop outlines, a 16-key systematic
   review rail, and coordinate QA. It is generated HTML/CSS using synthetic
   traces; no MEETI or other controlled clinical image is published.
3. **Visual language preserved.** White space, near-black typography, thin grey
   rules, teal workflow accents, blue box geometry, and amber failure treatment
   follow the reference. The page deliberately avoids gradients and ornamental
   card grids.
4. **Core workflow preserved.** The four stages remain a continuous left-to-right
   sequence on wide screens and an ordered vertical sequence on small screens:
   ROI capture, public OpenClaw image turns, crop/reconcile, and overlay/review.
5. **Evidence values preserved exactly.** GPT-5.6 Luna, 146.9 s, five image turns,
   111,833 tokens, 0.10–0.37 px drift, and 9,922 canonical MEETI images appear
   together with the required accuracy-miss warning.
6. **Unsafe concept copy intentionally replaced.** The generated concept showed
   example API-key commands. The implementation instead documents the actual
   subscription-backed `codex login` route and states that no Platform API key is
   stored in project files.
7. **Responsive behavior added.** At 760 px and below, navigation becomes an
   accessible disclosure, the hero and evidence stack, and long commands scroll
   inside their code blocks. Browser QA covered 1440, 901, 768, 390, and 320 px
   widths with no document-level horizontal overflow.
8. **Typography adapted for delivery.** The concept's editorial proportions are
   retained with local/system font stacks so GitHub Pages does not depend on a
   remote font request or third-party tracker.

QA used Playwright with installed Microsoft Edge because the Browser plugin was
not available in this environment. Both the accepted reference and final desktop
and mobile captures were visually inspected in the same review pass.
