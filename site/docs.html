Setup and verification guide.

Run the Windows co-reading loop from source or as a portable bundle, keep capture inside the configured ROI, and verify the public OpenClaw Gateway contract before a model sees an image.

Research software

Not a medical device. The physician retains the final diagnostic call.

Requirements

  • Windows 10 or 11.
  • uv for the repository-local Python environment.
  • Node.js 22+ for source runs; the portable bundle carries pinned Node.js.
  • A viewer window whose image area can be selected without PHI.
  • A local ChatGPT/Codex subscription sign-in only when using the subscription route.

Run from source

All dependencies stay inside the project environment and repo-local runtime.

uv sync --all-extras
scripts\install-openclaw-local.bat
start.bat

The app starts and stops its local Gateway automatically. On first launch, choose the viewer and save a capture ROI before enabling analysis.

Subscription-backed GPT-5.6 Luna

codex login

In Settings, select OpenAI Subscription via OpenClaw and choose openai/gpt-5.6-luna. The OAuth migration provider is enabled only to import local sign-in state into the isolated OpenClaw home, then removed from live plugin configuration before inference.

Ownership boundary

OpenClaw owns every image-analysis turn through public connect + chat.send. The bundle does not ship or enable a Codex agent runtime, and subscription setup does not retain a Platform API key.

ROI and privacy

  1. Open Settings or complete the first-run ROI setup.
  2. Select the target viewer and draw only the diagnostic image area.
  3. Exclude names, identifiers, timestamps, accession numbers, and surrounding desktop UI.
  4. Use manual re-trigger once to verify the captured frame before continuous monitoring.

Every refinement crop is a subset of the original ROI. Neither crop/refine nor overlay calibration is permitted to widen capture beyond that boundary.

Verify the image harness

The smoke produces a synthetic ECG, takes a non-zero ROI crop, sends one PNG attachment through the Gateway frame, and writes redacted evidence. 

uv run python scripts\run-image-harness-smoke.py ^
  --output data\harness-smoke\local

uv run python scripts\verify-image-harness.py ^
  --artifact-dir data\harness-smoke\local

The validator requires all of the following in the same evidence set:

  • public Gateway connect and chat.send frames;
  • one non-empty image/png attachment with hash and redacted content;
  • the production strict output hook and exact modality checklist;
  • meaningful image quality and next steps;
  • a bounded, non-full-viewer ROI capture;
  • positive normalized bbox geometry and overlay audit.

Build and verify the portable bundle

scripts\build-exe.bat
dist\DICOMOverlayAgent\DICOMOverlayAgent.exe --selfcheck
uv run python scripts\verify-packaged-app.py ^
  dist\DICOMOverlayAgent

The bundle includes the windowed Python/Qt app, pinned Node.js, the slim OpenClaw runtime, modality skills, and required workspace templates. It excludes Torch, model checkpoints, evaluation datasets, secrets, unused heavy Python libraries, Qt WebEngine/QML/Multimedia/PDF payloads, debug symbols, and foreign native binaries.

Do not prune OpenClaw internal dist chunks.

Those chunks are private implementation details of the pinned package. Size work is limited to build inputs, debug symbols, disabled surfaces, and non-Windows native payloads around the runtime.

Troubleshooting

Gateway port is occupied
The app reuses only a listener that completes an authenticated public connect. It refuses to terminate an unknown process.
App reports missing workspace templates
Rebuild with the current staging script. A package missing any pinned OpenClaw bootstrap template now fails verification.
Overlay is visibly offset
Re-run ROI setup on the target monitor and inspect the coordinate audit. DPI conversion drift above the calibrated threshold is a failure.
A model turn disconnects
Before acceptance the identical idempotent frame may replay once. After acceptance the client observes the same run and never creates a second charged turn.
